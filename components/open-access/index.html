Open access that works in practice.

Dex treats openness as production infrastructure, not a label. We commission artists, record high-quality source material, document provenance, publish practical file groupings, and provide attribution guidance for real projects.

Clear rights and attribution

A rights-forward public library.

Dex reduces the rights ambiguity that keeps artists, students, educators, and independent creators from using cultural material responsibly.

Reuse baseline

Unless an entry says otherwise, Dex catalog materials are released under Creative Commons Attribution 4.0 International.

  • Credit the artist and Dex.
  • Link to the source entry when possible.
  • Indicate if you changed the material.

Check the source

Each entry remains the authority for its files, credits, and any release-specific notes.
